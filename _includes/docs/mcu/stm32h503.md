## STM32H503 簡介
STM32H503 屬於 STM32H5 系列的入門款，搭載 Arm Cortex-M33 核心，聚焦低成本、高效能與增強安全性。

### 核心規格
- 250 MHz Cortex-M33，含 TrustZone
- 256 KB Flash / 64 KB SRAM（依料號略有差異）
- 豐富的 USART、SPI、I2C、ADC，並具備定時器與 PWM
- 低成本封裝選項，適合成本敏感方案

## 硬體配置提示
- 供電 1.71–3.6 V，注意與 I/O 電平相容
- 若使用 HSE，預留 8–25 MHz 晶振與適當負載電容
- SWD 針腳與 BOOT 針腳需避免浮接，便於開發與量產燒錄
- 若需安全隔離，可在 TrustZone 中分離關鍵外設

## 開發流程
1. 使用 STM32CubeMX 建立工程，配置時脈與外設
2. 啟用 TrustZone 時，先規劃安全/非安全區域，再生成程式碼
3. 先完成 UART log 與時脈驗證，確認基礎穩定
4. 逐步加入 ADC、PWM 或通訊外設，邊建構邊驗證

## 偵錯與安全
- 遇到 HardFault，印出 `CFSR`/`BFAR`，並查看 Stack frame
- 若啟用 TrustZone，留意安全/非安全的中斷配置
- 量產前鎖定調試口需先驗證韌體可 OTA/Bootloader 更新
