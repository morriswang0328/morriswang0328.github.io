## STM32G431 簡介
STM32G431 使用 Arm Cortex-M4F 核心，可達 170 MHz，適合需要高效能類比與馬達控制的應用。

### 核心規格
- 170 MHz Cortex-M4F，帶硬體浮點
- 512 KB Flash / 128 KB SRAM，可依料號調整
- 豐富的 ADC/DAC/OPAMP/COMP，適合電源與感測
- 支援 CAN FD、USB FS、USART、I2C 與 SPI

## 硬體配置備忘
- VDD 最低 1.71 V，可用內建 LDO 或 SMPS
- Boot0 需拉高才能進入系統 Bootloader，避免浮接
- 若使用 HSE，建議預留 8~25 MHz 晶振與 22pF 負載電容
- CAN FD 需要外部收發器，留意 120 Ω 匹配與終端電阻跳線

## 開發流程
1. 使用 STM32CubeMX 建立專案並匯出至 STM32CubeIDE
2. 啟用 RCC、時脈樹，確認 SysTick 及外設分頻
3. 先完成 USART log，方便後續除錯
4. 驗證 CAN FD：先以回圈 (loopback) 測試，再接上 bus
5. 使用 CMSIS-DSP 或 LL Driver 完成效能關鍵路徑

## 偵錯與量測
- SWD 針腳：SWCLK、SWDIO、NRST，預留 100mil 接針
- 若遇 HardFault，於 fault handler 內印出 `CFSR` 與 `BFAR`
- 量測 ADC 精度時，建議停用不必要的時脈並啟動校準 (ADCAL)
